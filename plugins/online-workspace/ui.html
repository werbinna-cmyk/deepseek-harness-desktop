在线工作区

GitHub 使用 device flow（无需 Secret）。在 GitHub → Settings → Developer settings → OAuth Apps 创建后填入 Client ID；浏览器打开 github.com/login/device 输入代码即完成登录。
Gitee 使用授权码模式（本地回调）。在 gitee.com → 设置 → 安全设置 → 第三方应用 创建后填入；授权回调地址填应用启动时提示的 http://127.0.0.1:<port>/callback。
本地目录；会话、上下文、文件、资源与代码会同步到 git 远端。换电脑时打开应用选择同一目录并连接同一平台即可拉取。
